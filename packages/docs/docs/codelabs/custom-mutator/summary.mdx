# Build a custom mutator

## 9. Summary

In this codelab, you learned:
- How to create a mutator in Blockly
- How to serialize and deserialize the mutator's extra state
- What UI options exist for Blockly mutators
- How to create a custom UI for a mutator
- How to fire events during a mutation
- When and how to use event groups
